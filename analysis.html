    Software and analysis

    Our research combines wet-lab research with bioinformatic analysis. All code is open-source and is freely available from github.

    Featured software

    damidBind

    damidBind completes the TaDa analysis pathway, formalising the downstream differential analysis pipelines for different types of DamID-seq data. In just a few commands, you can analyse two datasets and browse differentially bound peaks or transcribed genes in an embedded IGV browser, but there’s also a lot of customisation options for power users, if you want to dive under the hood.

    damidseq_pipeline

    damidseq_pipeline handles automatic alignment, read-extension, normalisation and background reduction for DamID-seq datasets. It’s the swiss-army-knife of TaDa analysis, over ten years old now and still going strong. It’ll handle just about anything you throw at it, including generating CATaDa coverage maps and even processing ChIP-seq data.

    find_peaks

    find_peaks is a simple yet robust FDR peak caller.  It was designed for use with DamID-seq datasets, but can be used on any file in bedgraph format (including ChIP-seq data).
