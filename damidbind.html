    damidBind

    damidBind is an R/Bioconductor package designed to provide a statistically robust, end-to-end workflow for differential analysis of DamID-seq data.

    The package is open-source and available from GitHub and Bioconductor. A comprehensive manual and vignette are available from those sites.

    Our publication on the software package in Bioinformatics takes a deep-dive into the nuts and bolts of DamID-seq analysis in the supplementary material, and is well worth the read.

    Key Features

    • Automated data integration: Seamlessly imports profiles generated by damidseq_pipeline and peak calls generated by the peak caller of your choice (BEDs, GFFs, or GenomicRanges objects)
    • Publication-ready visualisation: Includes high-quality volcano plots, GO plots, correlation heatmaps and diagnostic plots
    • Interactive genome browsing: Features a built-in Shiny app that integrates the IGV genome browser, allowing you to click on any differentially bound locus in a results table and instantly see the raw replicate binding, average condition binding and significant differential changes.
    • Functional Annotation: Direct interface with clusterProfiler for Gene Ontology (GO) enrichment analysis of bound or differentially bound genes.

    Installation

    You can install the latest stable version of damidBind from Bioconductor:

    if (!require("BiocManager", quietly = TRUE))
    install.packages("BiocManager")

BiocManager::install("damidBind")

    or the development version from Github.

    # install.packages("remotes")
remotes::install_github("marshall-lab/damidBind")
